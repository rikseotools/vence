Atajos de teclado del Explorador de Archivos de Windows 11:

**Navegación:**
- Alt + Flecha izquierda: Ir a la carpeta anterior
- Alt + Flecha derecha: Ir a la carpeta siguiente
- Alt + Flecha arriba: Subir un nivel (carpeta padre)
- Alt + D o Ctrl + L: Seleccionar barra de direcciones
- Ctrl + E o Ctrl + F: Seleccionar cuadro de búsqueda
- F3: Buscar un archivo o una carpeta en el Explorador
- F4: Mostrar lista de ubicaciones en la barra de direcciones

**Selección:**
- Ctrl + A: Seleccionar todos los elementos de la ventana
- Ctrl + clic: Seleccionar varios elementos individuales
- Mayús + clic: Seleccionar rango de elementos

**Operaciones con archivos:**
- F2: Renombrar elemento seleccionado
- Ctrl + C: Copiar
- Ctrl + X: Cortar
- Ctrl + V: Pegar
- Ctrl + Z: Deshacer
- Ctrl + Y: Rehacer
- Supr: Eliminar (a la Papelera)
- Mayús + Supr: Eliminar permanentemente
- Alt + Enter o Alt + Doble clic: Propiedades del elemento

**Ventanas:**
- Ctrl + N: Abrir nueva ventana del Explorador
- Ctrl + W o Alt + F4: Cerrar ventana actual
- Alt + P: Mostrar/ocultar panel de vista previa
- Alt + Mayús + P: Mostrar/ocultar panel de detalles
- Win + E: Abrir el Explorador de Archivos

**Vista:**
- Ctrl + Mayús + N: Crear nueva carpeta
- Ctrl + rueda del ratón: Cambiar tamaño de iconos
- Ctrl + Mayús + E: Expandir todas las carpetas del árbol en el panel de navegación
- Flecha izquierda (en árbol): Contraer la carpeta seleccionada
- Flecha derecha (en árbol): Expandir la carpeta seleccionada

**⚠️ Seleccionar todo: el atajo que cambió entre Windows 10 y Windows 11**

Es la confusión más frecuente de este tema, y conviene tenerla clara porque se pregunta mucho.

En el Explorador de archivos de **Windows 10 en español**, seleccionar todo era **Ctrl + E**. La versión española sustituía el atajo internacional (la «E» de «sEleccionar»), igual que hace con otros atajos localizados. En **Windows 11 esa localización se deshizo**: el atajo pasó a ser **Ctrl + A**, y **Ctrl + E** quedó reservado para llevar el foco al cuadro de búsqueda.

Por eso mucha gente que lleva años usando Ctrl + E nota de pronto que «ha dejado de funcionar». No es un fallo de su equipo: es un cambio de versión.

**No confundir con los documentos.** Dentro de una aplicación de documento (Word, Bloc de notas), la versión española sigue usando **Ctrl + E para seleccionar todo**, y ahí **Ctrl + A abre «Archivo > Abrir»**. Es decir, el mismo atajo hace cosas distintas según se esté en una carpeta o dentro de un documento.

Resumen para el examen:

| Dónde | Seleccionar todo |
|---|---|
| Explorador de archivos, Windows 11 | Ctrl + A |
| Explorador de archivos, Windows 10 en español | Ctrl + E |
| Dentro de un documento (Word, Bloc de notas), en español | Ctrl + E |

**Dónde comprobarlo (y cómo no perderse).** La fuente es la página oficial de Microsoft [Métodos abreviados de teclado en Windows](https://support.microsoft.com/es-es/windows/m%C3%A9todos-abreviados-de-teclado-en-windows-dcc61a57-8ff0-cffe-9796-cb9706c75eec), que se aplica a Windows 11 y Windows 10. Contiene **dos tablas distintas** y hay que mirar las dos:

- En la tabla **«Métodos abreviados de teclado de Windows»** (la general) está la fila **Ctrl + A — «Seleccionar todos los elementos de una ventana»**. El Explorador de archivos es una ventana, y de ahí sale la respuesta.
- En la tabla **«Métodos abreviados de teclado del Explorador de archivos»** están **Ctrl + E** y **Ctrl + F — «Seleccionar el cuadro de búsqueda»**. En esa tabla **no hay ninguna fila que asigne Ctrl + E a seleccionar todo**.

Conviene saberlo porque despista: si se busca Ctrl + A dentro de la tabla del Explorador **no aparece**, está en la general. Y no es un problema de traducción: la [versión en inglés de la misma página](https://support.microsoft.com/en-us/windows/keyboard-shortcuts-in-windows-dcc61a57-8ff0-cffe-9796-cb9706c75eec) dice lo mismo y con la misma estructura.

Un aviso sobre la documentación de Windows 10: esa página **nunca reflejó** la localización española del Explorador, así que para el atajo Ctrl + E de Windows 10 no hay cita oficial de Microsoft que aportar. Se conoce por el comportamiento real del sistema y por manuales en español, y sirve para entender de dónde viene la costumbre, no para alegarlo.

**Criterio ante una impugnación.** En informática los atajos cambian entre versiones y entre idiomas, y por eso son las preguntas que más reclamaciones generan. Un enunciado solo es defendible si acota la versión, y una alegación solo prospera si se apoya en la documentación oficial del fabricante **para esa versión concreta**. Lo que hace un equipo particular, por muy comprobado que se tenga, no es un argumento que se pueda sostener ante un tribunal: la vía que sí funciona es mirar qué versión fija el enunciado y llevar la cita del fabricante para esa versión.
