## Accesorios de Windows 11

Los **accesorios** son las aplicaciones sencillas que Windows incluye de serie para tareas cotidianas, sin necesidad de instalar programas de terceros. En Windows 11 se encuentran en el **menú Inicio → Todas las aplicaciones**, y muchos se abren escribiendo su nombre en el cuadro de búsqueda de la barra de tareas.

### 1. Bloc de notas (Notepad)

El **Bloc de notas** es el **editor de texto sin formato** incluido en Windows. Se utiliza para tomar anotaciones rápidas y guardarlas como **documentos de texto**, con extensión **`.txt`** por defecto.

> **Bloc de notas:** editor de texto incluido en el sistema operativo que permite crear y editar texto **sin formato**, y almacenarlo como documento de texto (`.txt`).

Su rasgo definitorio es precisamente que **no aplica formato** (ni negritas, ni tipos de letra por documento, ni imágenes): guarda solo los caracteres. Por eso se usa para notas, ficheros de configuración o código. Si se necesita formato, lo propio es un procesador de textos como Word.

No confundirlo con:
- **Paint**: editor de **imágenes** (dibujo y retoque básico).
- **Recortes**: captura de pantalla (total, de ventana o de una región).
- **Calculadora**: cálculos, con modos estándar, científica, gráfica y conversor de unidades.

### 2. Herramienta Recortes (Recortes y anotaciones)

La **Herramienta Recortes** (Snipping Tool renovada en Windows 11) es el accesorio para **capturar pantallas y anotarlas** sin salir de ninguna aplicación de terceros.

> **Herramienta Recortes:** aplicación de Windows para capturar y anotar la pantalla; incorpora captura de pantalla y grabación de vídeo de la pantalla en una sola app.

Se abre desde el botón Inicio buscando «herramienta recortes», o con dos atajos de teclado directos:

> Win + Mayús + S abre la superposición de la herramienta recortes para capturar una instantánea.

> Win + Mayús + R abre el modo de grabación de vídeo.

La tecla Impr Pant, pulsada sola, coloca una captura de pantalla completa en el Portapapeles sin necesidad de abrir la app.

Al capturar, hay cuatro modos disponibles:

> En el modo forma libre se dibuja una forma libre alrededor de un objeto.

> En el modo rectángulo se arrastra el cursor alrededor de un objeto para formar un rectángulo.

> En el modo ventana se selecciona una ventana, como un cuadro de diálogo.

> En el modo pantalla completa se captura toda la pantalla.

**Captura retardada:** permite preparar el contenido antes de capturar; se activa eligiendo un retraso de entre 1 y 5 segundos.

**Anotación tras la captura:** una vez hecha la captura, se puede dibujar sobre ella con los botones disponibles.

> El botón lápiz sirve para dibujar sobre la captura, y el botón marcador de resaltado para resaltar sobre ella. El botón borrador quita las líneas o formas ya dibujadas.

### 3. Símbolo del sistema (cmd)

El **Símbolo del sistema** es el **intérprete de línea de comandos** de Windows. Es el accesorio que se utiliza para **ejecutar comandos y programas en modo MS-DOS**, escribiendo instrucciones de texto en lugar de usar la interfaz gráfica.

> **Símbolo del sistema:** intérprete de comandos que permite ejecutar órdenes y programas escribiéndolos como texto, en modo MS-DOS.

Se abre escribiendo **`cmd`** en la búsqueda de la barra de tareas o en el cuadro **Ejecutar** (`Win + R`). Órdenes clásicas son `dir` (listar el contenido de una carpeta), `cd` (cambiar de directorio) o `ipconfig` (ver la configuración de red).

Junto a él conviven en Windows 11 otras dos consolas, más modernas y con más capacidades:
- **PowerShell**: consola orientada a la automatización y administración del sistema.
- **Terminal de Windows**: aplicación que agrupa en pestañas el Símbolo del sistema, PowerShell y otras consolas.

### 4. Cómo se abren

| Accesorio | Vía rápida |
|---|---|
| Bloc de notas | Buscar «Bloc de notas», o `notepad` en Ejecutar (`Win + R`) |
| Herramienta Recortes | `Win + Mayús + S` para capturar una región, o buscar «Recortes» |
| Símbolo del sistema | Buscar «cmd», o `cmd` en Ejecutar |
| Calculadora | Buscar «Calculadora» |
| Paint | Buscar «Paint», o `mspaint` en Ejecutar |
