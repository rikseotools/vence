# Atajos de teclado en Excel 2016

> ⚠️ **Se examina el Excel INSTALADO EN ESPAÑOL**, que localiza los atajos de letra por la inicial de la acción en castellano. Entre paréntesis se indica el equivalente de la versión inglesa, que es el distractor habitual y el que aparece en la documentación traducida de Microsoft.

## 1. Archivo

| Atajo | Acción |
|---|---|
| **Ctrl+U** | nuevo libro (en inglés, Ctrl+N) |
| **Ctrl+A** | abrir (en inglés, Ctrl+O) |
| **Ctrl+G** | guardar (en inglés, Ctrl+S) |
| F12 | Guardar como |
| Ctrl+P | imprimir |
| Ctrl+Z / Ctrl+Y | deshacer / rehacer |
| Ctrl+W | cerrar el libro |

## 2. Desplazamiento

| Atajo | Acción |
|---|---|
| **Inicio** | **ir al principio de la fila** (a la columna A) |
| Ctrl+Inicio | ir a la celda A1 |
| Ctrl+Fin | ir a la última celda con datos |
| Ctrl+flecha | saltar al borde del rango de datos |
| Ctrl+Av Pág / Ctrl+Re Pág | hoja siguiente / anterior |
| **Alt+Av Pág** | **desplazar una pantalla a la derecha** |
| **Alt+Re Pág** | **desplazar una pantalla a la izquierda** |
| F5 | cuadro Ir a |

## 3. Selección

| Atajo | Acción |
|---|---|
| **Ctrl+barra espaciadora** | **seleccionar toda la columna** |
| Mayús+barra espaciadora | seleccionar toda la fila |
| Ctrl+E | seleccionar toda la hoja |
| Mayús+flecha | ampliar la selección |
| Ctrl+Mayús+flecha | ampliar hasta el borde del rango |

## 4. Edición

| Atajo | Acción |
|---|---|
| F2 | editar la celda activa |
| Intro / Tab | confirmar y bajar / confirmar y ir a la derecha |
| **Esc** | **cancelar la acción o cerrar el cuadro de diálogo** |
| Ctrl+D / Ctrl+R | rellenar hacia abajo / hacia la derecha |
| Ctrl+Mayús+V | pegado especial |
| Supr | borrar el contenido |
| Alt+Intro | salto de línea dentro de la celda |
| **F7** | **abrir el cuadro de Ortografía** |

## 5. Formato

| Atajo | Acción |
|---|---|
| Ctrl+1 | cuadro Formato de celdas |
| **Ctrl+N** o **Ctrl+2** | **aplicar o quitar NEGRITA** (las dos combinaciones son válidas: Ctrl+N es la localizada y Ctrl+2 la numérica) |
| **Ctrl+K** o Ctrl+3 | cursiva |
| **Ctrl+S** o Ctrl+4 | subrayado |
| Ctrl+5 | tachado |
| **Ctrl+Mayús+&** | **aplicar contorno a las celdas seleccionadas** |
| Ctrl+Mayús+_ | quitar el contorno |
| Ctrl+Mayús+1 / 4 / 5 | formato de número / moneda / porcentaje |

## 6. Fórmulas, filas y columnas

| Atajo | Acción |
|---|---|
| F4 | alternar el tipo de referencia |
| F9 | recalcular |
| Ctrl+Mayús+Intro | introducir una fórmula matricial |
| Ctrl+Mayús++ / Ctrl+− | insertar / eliminar celdas |
| Ctrl+T | crear tabla |

---

## 7. La ficha Vista: grupo Mostrar

Contiene las casillas **Regla, Líneas de cuadrícula, Barra de fórmulas** y **Encabezados**.

> **Si en la hoja se ven las celdas pero no las letras de las columnas ni los números de las filas, lo que ha ocurrido es que se ha desactivado la casilla «Encabezados» del grupo Mostrar** (ficha Vista). No es un problema de zoom ni de protección.

## 8. La barra de estado

De forma predeterminada muestra, con un rango seleccionado, el **Promedio**, el **Recuento** y la **Suma**, además del modo de celda, los botones de vista y el zoom. Se personaliza con el botón derecho sobre ella.

## 9. Un caso de texto frecuente

Para pasar nombres escritos en mayúsculas a la forma «Nombre Apellido» (inicial mayúscula y resto minúsculas) la función es **`=NOMPROPIO(A2)`**. `MAYUSC` pondría todo en mayúsculas y `MINUSC` todo en minúsculas.
