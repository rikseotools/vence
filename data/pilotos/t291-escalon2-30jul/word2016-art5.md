# Atajos de teclado en Word 2016

> ⚠️ **Se examina el Word INSTALADO EN ESPAÑOL**, que localiza los atajos de letra por la inicial de la acción en castellano (Ctrl+**G**uardar, Ctrl+**N**egrita, s**E**leccionar…). La documentación traducida de Microsoft muestra las teclas de la versión **inglesa**, que son los distractores típicos.

## 1. Archivo

| Atajo | Acción |
|---|---|
| **Ctrl+U** | nuevo documento (inglés: Ctrl+N) |
| **Ctrl+A** | abrir (inglés: Ctrl+O) |
| **Ctrl+G** | guardar (inglés: Ctrl+S) |
| F12 | Guardar como |
| Ctrl+P | imprimir |
| Ctrl+W o Ctrl+F4 | cerrar el documento |
| **Alt+F4** | **cerrar el documento y la aplicación** |
| Ctrl+Z / Ctrl+Y | deshacer / rehacer |

## 2. Edición y portapapeles

| Atajo | Acción |
|---|---|
| Ctrl+C / Ctrl+X / Ctrl+V | copiar / cortar / pegar |
| **Ctrl+Insert** | **equivale a Copiar** |
| Ctrl+E | seleccionar todo |
| Ctrl+B / Ctrl+L / Ctrl+I | buscar / reemplazar / ir a |
| **Esc** | **cancelar la acción o cerrar el cuadro de diálogo** |
| **Copiar formato** | Inicio ▸ Portapapeles. Con **un clic** se aplica una vez; **con DOBLE CLIC en el botón queda activo** para aplicarlo a varios sitios seguidos hasta pulsar Esc |

## 3. Formato de carácter

| Atajo | Acción |
|---|---|
| **Ctrl+N** | negrita |
| **Ctrl+K** | cursiva |
| **Ctrl+S** | **subrayar el texto seleccionado** |
| **Ctrl+Mayús+>** | aumentar el tamaño de fuente |
| **Ctrl+Mayús+<** (en el teclado español basta **Ctrl** y el símbolo **<**) | **reducir el tamaño de fuente** |
| Ctrl+Espacio | quitar el formato de carácter |
| **Mayús+F3** | **alternar entre primera letra en mayúscula, TODO MAYÚSCULAS y todo minúsculas** |

## 4. Párrafo

| Atajo | Acción |
|---|---|
| Ctrl+Q / Ctrl+T / Ctrl+D | alinear a la izquierda / centrar / alinear a la derecha |
| **Ctrl+J** | **aplicar alineación justificada al párrafo seleccionado** |
| Ctrl+1 / **Ctrl+5** / Ctrl+2 | interlineado sencillo / **de 1,5 líneas** / doble |
| Ctrl+Mayús+8 | mostrar u ocultar las marcas de párrafo |

## 5. Saltos y notas

| Atajo | Acción |
|---|---|
| **Ctrl+Intro** (Ctrl+Enter) | **insertar un salto de página manual** (el que se usa cuando no se quiere esperar al salto automático que Word inserta al llenarse la página) |
| **Ctrl+Alt+O** | insertar **nota al pie** |
| **Ctrl+Alt+L** | **insertar nota al final** |
| Mayús+Intro | salto de línea **dentro del mismo párrafo** |

> **Intro y Mayús+Intro no son lo mismo: con Intro se crea un párrafo nuevo; con Mayús+Intro se baja de línea sin abandonar el párrafo**, de modo que el texto conserva el formato de párrafo y no recibe viñeta ni numeración nueva.

### 5.1 Saltos de sección

Desde *Disposición ▸ Configurar página ▸ Saltos*:

- **Continuo** — **la nueva sección empieza en la MISMA página**, justo tras el texto anterior. Sirve para cambiar el número de columnas o los márgenes a mitad de página.
- **Página siguiente** — la nueva sección empieza en la página siguiente.
- **Página par** / **Página impar** — la nueva sección empieza en la siguiente página par o impar, **dejando en blanco la intermedia si hace falta**.

## 6. Vista, cinta y ventanas

| Atajo | Acción |
|---|---|
| **Alt** | **el método más rápido para acceder a la cinta de opciones**: muestra los KeyTips sobre cada ficha |
| **F10** | **activa o desactiva los KeyTips**, igual que Alt |
| **Ctrl+F1** | mostrar u ocultar (contraer) la cinta de opciones |
| **Ctrl+F10** | **maximizar la ventana del documento** |
| Ctrl+F6 | pasar al siguiente documento abierto |
| **Ctrl+Mayús+E** | **activar o desactivar el Control de cambios** |
| **Ctrl+Mayús+G** | **abrir el cuadro Contar palabras** (páginas, palabras y caracteres) |

## 7. Tablas

| Atajo | Acción |
|---|---|
| Tab / Mayús+Tab | celda siguiente / anterior |
| **Alt+Re Pág** | **ir a la primera celda de la columna** |
| Alt+Av Pág | ir a la última celda de la columna |
| Alt+Inicio / Alt+Fin | primera / última celda de la fila |

## 8. Vista Esquema

En **Vista ▸ Esquema**, la opción **«Mostrar solo el primer nivel»** **filtra la visualización para mostrar únicamente los títulos de nivel 1**, contrayendo todo lo demás. Es una forma de ver la estructura del documento; no elimina contenido.

## 9. Notas al pie

Una **nota al pie** **se relaciona con el texto del documento mediante una llamada**: un número en superíndice que Word inserta en el punto del texto y repite al pie de esa misma página, donde se escribe la aclaración. Se numeran automáticamente y se renumeran solas al añadir o quitar notas.
